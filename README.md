# Manual Testing of Priyo.com

## Project Overview
This project encompasses a comprehensive manual testing approach for Priyo.com, a prominent Bangladeshi news and content platform. The repository includes detailed test cases aimed at ensuring the website's functionality, usability, and reliability.



## Test Coverage
The test cases in the Excel file address the following areas:

- **Homepage Functionality:** Verification of news feed loading, banner displays, and navigation elements.

- **User Authentication:** Testing login, registration, and password recovery processes.

- **News Categories:** Ensuring proper loading and navigation of different news sections.

- **Search Functionality:** Assessing the accuracy and responsiveness of the search feature.

- **Responsive Design:** Evaluating the website's adaptability across various devices and screen sizes.

- **Performance Testing:** Observing page load times and responsiveness under different conditions.

- **Error Handling:** Checking for appropriate error messages and handling of invalid inputs.

## Tools Used
- **Microsoft Excel:** For documenting and organizing test cases.

- **Web Browsers:** Google Chrome, Mozilla Firefox, and Microsoft Edge for cross-browser testing.

- **Developer Tools:** Browser DevTools for inspecting elements and monitoring performance.

## Test Case Format

Each test case in the Excel file includes the following fields:

- **Test Case ID:** Unique identifier for the test case.

- **Test Scenario:** Brief description of the functionality being tested.

- **Preconditions:** Any prerequisites before executing the test.

- **Test Steps:** Detailed steps to perform the test.

- **Expected Result:** The anticipated outcome of the test.

- **Actual Result:** The actual outcome observed during testing.

- **Status:** Pass/Fail based on the comparison of expected and actual results.

- **Remarks:** Additional notes or observations.
